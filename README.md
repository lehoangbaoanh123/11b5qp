# Ôn Tập Trắc Nghiệm GDQP & AN Lớp 11 (11B5)

Website ôn tập trắc nghiệm môn Giáo dục Quốc phòng & An ninh lớp 11 chuẩn theo đề cương ôn tập GK1.

## ✨ Tính năng nổi bật
- **Đồng hồ đếm ngược 45 phút** chuẩn theo thời gian thi thực tế, tự động nộp bài khi hết giờ.
- **Giữ nguyên thứ tự câu hỏi** theo đúng đề cương gốc (52 câu trắc nghiệm chia theo từng bài học).
- **Tráo ngẫu nhiên đáp án A, B, C, D** (thuật toán Fisher-Yates) mỗi lần tải trang hoặc làm lại bài, giúp học sinh rèn luyện tư duy, không học vẹt vị trí chọn.
- **Hệ thống chấm điểm chi tiết**: hiển thị số câu đúng, số câu sai, tỷ lệ phần trăm và đối sánh chi tiết phương án học sinh chọn với đáp án chuẩn.
- **Giao diện Trắng - Đen tối giản (Minimalist B&W)** hiện đại, thanh lịch, độ tương phản cao.
- **Tối ưu trải nghiệm di động**: Nút bấm kích thước lớn (min 52px), font chữ 16.5px dễ đọc, có bảng chuyển nhanh tới bất kỳ câu hỏi nào.
- Tự động hiển thị sơ đồ phân định vùng biển Việt Nam (Câu 16).

## 🚀 Cách kích hoạt GitHub Pages để làm bài trực tuyến
1. Vào repository trên GitHub: `https://github.com/lehoangbaoanh123/11b5qp`
2. Chọn tab **Settings** > Mục **Pages** ở thanh menu bên trái.
3. Ở phần **Branch**, chọn `main` (hoặc `master`), thư mục `/ (root)`, sau đó bấm **Save**.
4. Chờ 1-2 phút, GitHub sẽ tạo đường link web trực tuyến dạng:
   `https://lehoangbaoanh123.github.io/11b5qp/`
